# NoNameTSBWebsite

Public site for the TSB clan bot — leaderboard, lineup, blacklist, trainers, and wars.

## Setup

```bash
npm install
copy .env.example .env
npm run dev
```

Set `VITE_API_URL` to the API (`http://localhost:8787`).

Deploy the `NoNameBotWebsite` folder to Vercel.
